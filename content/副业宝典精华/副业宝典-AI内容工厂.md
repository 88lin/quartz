# 一、AI 短剧（《文生图 AI 短剧制作变现》，全书内容赛道里 SOP 最完整的一章）

**工具选型**：零成本起步用 LiblibAI/堆友（集成 SD，每日免费额度，社区有现成国风/二次元模型）；进阶 Midjourney 约 70 元/月（审美下限高、省后期修图）。配音用剪映专业版文本朗读或魔音工坊（选"悬疑解说音""大叔音"这类有辨识度的音色）。

**题材定生死**：避开动作片和复杂特效片。推荐悬疑解谜、职场吐槽、情感鸡汤、民间故事——静帧+运镜+强剧情就能撑起来，民间故事和悬疑在中老年与下沉市场有巨大流量红利。

**制作 SOP 四件事**：
1. **剧本为"好画"而写**：AI 听不懂潜台词，不写"小明很伤心"，写"特写，小明坐在雨中，低头，眼角有泪，冷色调"。
2. **前 3 秒定生死**：第一句台词必须抛出冲突悬念——"昨晚，我看见死去的邻居又回来了……"
3. **角色一致性**（最大痛点）：固定 Seed + ControlNet；Midjourney 用垫图 + `--cref`；土法是少拍正脸特写，多用侧脸、背影、手部道具特写，靠观众脑补维持连贯。
4. **声音与剪辑**：静态图加关键帧做缓慢推拉（Ken Burns 效果），配开门声、脚步声、心跳声——静态图立刻有电影感。

**冷启动三招**：
1. **三号赛马**：A 号悬疑、B 号职场、C 号情感，连发一周，播放破 5000 的留下、其余弃掉——最低成本的赛道试错。
2. **评论区截流**：去同类头部爆款视频下发神评论/干货，用小号提问大号回答。
3. **蹭标签与 BGM**：带宽泛高流量标签（#民间故事 #职场 #深夜故事），用平台热门卡点音乐吃流量扶持。

**留存三招**：永不一条讲完，高潮处戛然而止打"关注看下集"；建合集（《诡异出租屋系列》）拉账号权重；前 10 条评论必回且带反问（"你也遇到过这种老板吗？"）制造活人感。私域用"高清壁纸/提示词模板/教你不用电脑做同款"引流入群，发新片红包"炸群"拉基础播放。

**变现三阶段**：
- 起步期（0-1 万粉）：中视频/创作分成，万播 15-30 元；网盘拉新（评论区置顶"原图已打包"，夸克/迅雷注册返 3-5 元/人）。
- 成长期（1-10 万粉）：橱窗带货（书籍转化率最高，如《民间故事全集》）；星图商单 500-2000 元/条。
- 成熟期（10 万粉+）：收徒卖课（利润率最高的环节）；IP 定制单条 5000 元+。

**指标**：北极星是 5 秒留存率 >40%；平均播放时长 >15 秒；互动（赞评藏）>5%。文生视频短剧（Runway/Luma 类工具）是同一打法的另一形态（Runway/Luma 类工具，成本 200-500 元/月订阅）。

**坑**：严禁录屏搬运，画面必须 AI 重绘或深度二创；角色避开明星脸防肖像权索赔；前 5 条视频 0 播放是正常数据，复盘完播率和 5 秒流失率，微调开头和封面，不要弃号。

# 二、AI 漫剧/推文流水线

管线：GPT/DeepSeek 把爽文剧情拆成画面描述词 → Midjourney `--cref` 或 Flux LoRA 保证角色一致 → Python 脚本调 ComfyUI 批量生成分镜 → Runway/Luma 动态化 → 剪映 AI 配音合成，单条可压到 30 分钟。

**账本**：订阅+算力 300-800 元/月；变现三条——平台流量分成、网文推文转化（6-10 元/人）、代运营/定制单条 200-500 元。模拟案例（虚构）：后端老王把代码 Bug 抽象成"心魔"怪物做《程序员修仙传》，ComfyUI Workflow 统一画风，靠云算力推荐和课程推广做到副业超工资 50%。

**坑**：AI 画风趋同容易被判"低质同质化"，必须加独特滤镜/剪辑节奏；AI 不懂分镜逻辑，关键帧衔接要人工微调；生图模型必须可商用，剧本要有授权或大幅二创。

# 三、AI 辅助网文（《AI 辅助网文流水线写作》，确定性最高的一条）

**平台选择决定变现效率**：首选番茄/七猫——推荐算法主导、不看名气、只看完读率，变现靠免费读者广告分成；起点/晋江门槛高，AI 只配当辅助；知乎短篇（1-2 万字脑洞文）变现周期短。

**三明治分工**：人定世界观/核心梗/大纲/人物小传 → AI 扩写场景、对话、环境、打斗 → 人润色逻辑、统一文风。工具选长文本强的（Kimi/DeepSeek 处理大纲续写，文心/星火生成古风辞藻），Prompt 库工程化（例："以'凡人修仙'风格描写主角进入阴森洞穴，突出寒气和未知恐惧，500 字"）。

**冷启动**：把前三章冲突点用 Midjourney/即梦生成 3-5 张插图 + 剪映图文成片，抖音/小红书发"#书荒 发现一本神书，男主竟然……"，评论区置顶"去 XX 小说搜《书名》"；知乎/小红书发书单软文（推 5 本、1 本是自己的），吃搜索长尾。

**留存**：黄金三章（第一章核心冲突、第三章第一个高潮）；每章结尾必须是悬念（专门让 AI 把章尾改写成 hook）；日更 4000-6000 字雷打不动——确定性即留存；章末投票"主角该杀还是该放，扣 1 扣 2"做参与感。

**账本与止损纪律**：万次阅读 20-50 元；单本月分成 1500-8000，中等书 1500-3000 是常态；矩阵多本稳定期 5000-1 万。**10 万字首秀数据差就切书**——AI 辅助下开新书成本极低，不要对单本有感情。北极星指标：完读率 >15%（10 万字口径）。一鱼多吃：完结书转 AI 有声书上喜马拉雅、AI 翻译出海发 Webnovel/Kindle（见 [[副业宝典-AI翻译出海]]）。

# 四、AI 漫画 IP

画师画一话要一周，AI 20 分钟/话。路径：训练核心角色 LoRA → GPT 生成轻小说脚本 → Diffusion 批量条漫 → 小红书/推特连载，"点赞决定下一话剧情"锁定种子粉。

- 引流："假如 AI 续写了[热门番剧]没拍出的结局"（争议+共鸣）；LOFTER/半次元发"赛博朋克风/新中式"设定图。
- 私域：知识星球卖"IP 共创权"——付费粉丝才能参与角色命名、CP 走向。
- 账本：订阅 19/月、定制壁纸周边 49/件；启动 3000 元（4090 云算力+订阅）；推演 500 订阅者月入过万，多 IP 矩阵 4 万/月。
- 模拟案例（虚构）："赛博武汉"LoRA 每天一页《现代道士下山》，3 个月 3 万粉，动作连贯性靠 ControlNet 骨架控制解决，品牌植入月 5000+。

**坑**：平台对纯 AI 图有降权趋势，后期要加手绘微调；洗稿和版权争议基座模型严禁商用；核心竞争力在"故事的离谱程度"，不在画风。

# 五、AI 工具测评自媒体

不做"工具列表"搬运（已没人看），做垂直场景的 Wow Moment："如何用 AI 十分钟开发一个 Chrome 插件""AI 如何帮我自动化处理 500 个 Excel 报表"。

- 内容流水线：GPT 写脚本 → HeyGen 数字人出镜（保护隐私）→ 自动剪辑多平台分发。
- 变现：CPS 分销（AI 编程助手每付费用户抽 30-50%，单转化 10-100 元）+ 粉丝破万后星图商单 2000-20000 元/条。
- 模拟案例（虚构）：视频号分享用 Cursor 重构旧代码，一条破百万播放，转做"AI 职场开挂系列"，成为三家初创 AI 公司的推广合伙人并卖出几千份课。
- 坑：硬广必限流，广告要融进解决问题的教学过程；工具迭代快，推荐的东西下架就是内容失效，保持信息更替速度。

# 六、表情包（《表情包变现》，门槛最低的一章）

- **定位三选一**：职场宣泄（甄嬛传截图+线条小狗配扎心文案，工作日早晨和周五下午传播最高）；垂类圈层（考研考公/铲屎官/原神——圈子越窄共鸣越强）；情侣暧昧类（刚需、愿付费）。
- **二创捷径**：不从零画图，熊猫头/悲伤蛙配新文案翻新；工具醒图/美图秀秀/花熊即可。
- **分发**：小红书（首图+聊天场景演示+9 张纯图，标题带情绪"家人们谁懂啊，这张图太好用了"）；微信表情开放平台必做（审核慢，但用户聊天使用=免费裂变，做成系列 IP"某某的打工日记"）。
- **引流与裂变**：图上打轻微水印，"无水印原图进群取图"；去热门视频评论区发自己的表情包，被顶置后流量溢出到主页；热点爆出半小时内出"吃瓜表情包"（爆梗响应 <2 小时）；边角留极小 ID——图片在群里疯传就是免费广告。
- **变现组合**：微信赞赏（1-5 元/笔，爆款发送量过亿仅赞赏可达数千，长尾被动）；取图小程序（万粉号月 1500-4000，日 300-800 次下载 × 0.15 元广告）；B 端定制（企业吉祥物表情 3000-10000/套）；周边 POD。万粉量级综合月 3500-1 万（推演）；书中同时给了现实锚点：多数兼职者月几百到两三千才是常态。
- **坑**：严禁明星、影视剧原片商用变现（取图收费即潜在违规）；擦边/负能量图限流封号；不做自己喜欢的图，做数据（点赞/下载）验证过的图。
