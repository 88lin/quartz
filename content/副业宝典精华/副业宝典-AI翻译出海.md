# 一、账本：全书价差最扎实的一组

| 项目 | 你收 | 人工对照价 | 你的 API 成本 |
|---|---|---|---|
| 网文翻译 | 50 元/万字 | 200-500 元/千字 | ≈5 元/万字（毛利 >80%） |
| 短剧轻量翻译（字幕） | 1000 元/部 | 人工一部几万美金 | 500-1500 元 |
| 短剧全套配音+对嘴 | 5000 元/部 | — | 500-1500 元（毛利约 60%） |
| 视频本地化 | 50 元/分钟 | 人工一集几百块、3 天 | ≈2 元/分钟（毛利 95%+） |
| 游戏多语言 | 299 元/万字 或 99 元/月订阅 | — | 5-10 元/万字 |

启动成本：网文 1000 元（API 预存）、短剧 5000 元（买高级接口点位）、视频 1000 元、游戏 500 元。书中推演：网文接几个工作室"全量包"月入 3 万+，回本点 = 翻译满 20 万字；短剧签 2 个发片方回本，天花板月 5 万+。

# 二、网文出海（ch388）

**验证**：去 Webnovel（阅文海外版）作者论坛发帖，提供"免费试译 5000 字"。

**产品三件**：
1. **翻译管家**：LLM + 专有名词库——书中举的反例是"九龙拉棺"被翻成"九条龙拖着棺材"。用 RAG 保证"金丹、筑基"这类词全文统一。
2. **配套素材**：一键生成符合欧美/东南亚审美的英文封面和预告 Banner（Stable Diffusion）。
3. **分发机器人**：自动同步更新到 Webnovel、GoodNovel 的作者后台——这是"管家"溢价所在。

**获客**：知乎/公众号发《我是如何靠 AI 把 200 万字网文瞬间出海月入过万的？》；沉淀进各"新人签约群"；对顶尖作者做"IP 全案出海陪跑"。模拟案例（虚构）：给玄幻作者做出海流程后拿 10% 长尾分账。

**KPI**：海外读者追更率/付费留存；信达雅抽检（海外母语者打分）；封面点击率。书中 OKR：50 个垂直品类名词字典、单章 3000 字翻译压到 2 分钟。

**坑**：各国暴力尺度不同，管线内置敏感词预过滤；部分平台禁 AI 直译作品，需要人工润色接口"掩护"——擦边操作，客户合同里写清责任归属。

# 三、短剧配音出海（ch387）

**验证话术**：在 LinkedIn/Twitter 找短剧分发账号，直接问："如果能用 AI 自动把你的中文短剧转成地道的英语/西班牙语，且嘴型保持同步，价格只要人工的 1/10，你想看 Demo 吗？"

**管线**：UVR 擦除背景声保人声 → DeepL/GPT-4 结合当地俚语做剧本转写 → HeyGen/Rask.ai 音色克隆 + 口型匹配。技术栈 Python + FastAPI + ffmpeg + TTS 接口。

**模拟案例（虚构）**：先帮小工作室做 5 集试播，反馈好直接签全季 50 集。

**坑**：人声分离会伤 BGM，要二次润色；欧美观众偏好更夸张的语调，翻译不能死抠文字；配音克隆和存储要落在合规区域，注意肖像权。

# 四、视频本地化管线（ch372）

**MVP 四步**：Whisper 提取台词 → GPT-4 剧本级翻译（书中给了现成提示词："你是 Netflix 字幕组，请用美式俚语翻译"）→ ElevenLabs 多角色配音 → Wav2Lip 调口型（可选）。

**获客**：Fiverr/Upwork 挂"Video Localization Service"直接赚美金；跨境电商圈宣传"低成本多语言产品介绍视频"；TikTok/YouTube 用工具把国内爆款转成英语/西语/印尼语发布测流量。

**坑**：直接搬运他人视频出海必然侵权——只服务有版权的客户，或做二创解说；简单搬运会被 TikTok 查重，需混剪、镜像、变速、加滤镜。

**模拟案例（虚构）**：把"修驴蹄"解压视频做英文解说，脚本自动下载→提取文案→改写→配音→合成，日更 10 条 YouTube Shorts，一个月后单条最高 500 万播放、广告分成 $2000。

# 五、游戏多语言（ch389）——最容易被忽视的工程件

游戏翻译不是文字转换：要处理 UI 长度适配（译文撑破按钮）、语境（"Miss"是"想念"还是"未击中"）、专有名词一致性。

**验证话术**：去 Unity 开发者社区或 Discord 的"Indie Game Dev"频道问："有一个能自动读你项目里的多语言表、结合游戏语境一键生成 10 种语言、并自动检测文字超出 UI 的工具，9.9 美金/月，你订阅吗？"

**方案**：脚本一键提取 Excel/JSON/Unity Localization 表 → 把游戏世界观、角色背景作为 Context 喂给 Claude 3.5/GPT-4o → Web 看板自动标红会导致 UI 错位的条目。

**定价**：299 元/万字或 99 元/月；API 成本 5-10 元/万字；启动 500 元。北极星指标：单项目"免人工修正率"。OKR：与 Unity/Unreal/Godot 做插件级对接。

**坑**：泰语、阿拉伯语等小语种排版逻辑特殊，需要专门的检测算法；客户的源码和文本必须承诺保密。
