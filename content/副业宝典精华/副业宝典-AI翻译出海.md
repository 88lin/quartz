## 项目逻辑

中国网文、短剧、游戏出海是当下确定性最高的内容红利，瓶颈在本地化：一部短剧人工翻译+配音要几万美金。你不做内容，做"把内容运出去"的物流：

- **网文**：LLM + 专有名词库（RAG 保证"金丹/筑基"这类词前后统一）+ 出海封面生成 + 分发机器人同步 Webnovel/GoodNovel 等平台后台。
- **短剧**：UVR 擦音轨保人声 → DeepL/GPT 结合当地俚语翻译 → HeyGen/Rask 音色克隆 + 口型匹配。
- **视频/游戏**：同一管线换成字幕/多语言 UI，加 UI 文本溢出检测等工程件。

## 账本（价格锚点可信，收入为推演）

| 项目 | 价格锚点 | 成本 |
|---|---|---|
| 网文翻译 | 50 元/万字（人工 200-500 元/千字） | 启动 1000 元 API 预存，毛利 >80% |
| 短剧轻量翻译 | 1000 元/部 | API 500-1500 元 |
| 短剧全套配音+对嘴 | 5000 元/部 | 毛利约 60% |
| 视频制作 | 50 元/分钟（API 成本约 2 元/分钟） | 启动 1000 元 |
| 游戏本地化 | 299 元/万字或订阅 99 元/月 | — |

推演：接 1 个工作室的"全量包"月入 3 万+；翻译满 20 万字回本。模拟案例（虚构）：给玄幻作者做出海流程，拿了 10% 长尾分账；另一个把"修驴蹄"视频做英文解说，单条播放 500 万、广告分成 $2000——属于幸存者叙事，看链路即可。

## SOP

1. **验证**：Webnovel 作者论坛发"免费试译 5000 字"；或 LinkedIn/Twitter 找短剧分发号，直接问"AI 转英语/西语、口型同步，价格人工 1/10，想看 Demo 吗"。
2. **建名词库**：50 个垂直品类（修仙/女频）术语字典，RAG 保证一致性——这是和裸机翻拉开差距的全部。
3. **按部交付**：轻量翻译（字幕）试水 → 配音对嘴全套（客单 ×5）→ API 级批量协同（绑定发片方）。
4. **复用**：同一管线横向切品类（网文→短剧→游戏→课程视频），边际成本递减。

## 风险与坑

- **平台禁 AI 直译**：部分平台要求人工润色，书中建议走"人工润色接口"——属于擦边操作，客户合同里要写清责任。
- **文化合规**：各国暴力/宗教尺度不同，管线里必须内置敏感词预过滤和本地化合规词库。
- **版权陷阱**：直接搬运他人视频出海必被查重，只服务有版权的客户，或做二创解说。
- **口型与音质**：人声分离会伤 BGM，需要二次润色；这是客户能直接感知的质量点。
- 数据存储要选合规区域，避免肖像权纠纷（配音克隆需授权）。
