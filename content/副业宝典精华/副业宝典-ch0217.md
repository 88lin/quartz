> 可信度 ★★★☆☆｜类型：服务外包（撮合）｜变现：技术背书报告费 ¥800-¥1,500 + 固定入职服务费 ¥1万-¥3万｜门槛：中 + GitHub 数据爬取与人才评分模型

传统猎头只看关键词，分不清"大厂架构师"和"写 PPT 的架构师"，还收 20% 年薪。卖"从 GitHub/StackOverflow 全网代码画像精准定位 + Agent 自动简历解析与初步技术面评测"，赚企业的入职服务费。（撮合簇 ch203/ch217 同源：抽佣+防跳单，本章为数据驱动猎头版。）

**做法**
- MVP（¥0）：严禁直接采购昂贵招聘库账号。第一步：用 Python 脚本针对特定赛道（Rust 高性能计算、LLM 推理优化）在 GitHub/StackOverflow 爬取活跃 Expert；第二步：用 LLM 自动生成每人的"技术力深度报告"（代码规范度、架构思维、疑难问题解决能力）；第三步：找 2 家急需人才的初创公司，以"首人入职仅收 ¥5,000"验证闭环。
- 引流：即刻/掘金发"为什么你招不到好的 Rust 程序员？因为好的人全在这些 GitHub 库里"，晒分析热力图吸引 CTO；用 AIGC 发《2025 全球顶级 AI 模型专家人才分布地图》。
- 钩子：领《技术负责人专用：如何通过 10 行代码看破候选人的架构水平指南》。
- 模拟案例（小A）：做"人才探雷器"，专攻国内公司找东南亚、东欧远程开发者的需求，报告直接附候选人在 GitHub 解决过的最难 Bug 链接，老板不到一周定人。

**账本（书中推演数字）**
- 每月撮合 3 名兼职/远程高端专家或 1 名全职总监；启动成本 ¥0。
- 单个候选人硬核技术背书报告费 ¥800-¥1,500；成功入职服务费（固定制而非比例制）¥10,000-¥30,000/人；单月毛利 ¥2万-¥5万+（自动化搜人/解析/邀约，一人顶 5 个传统猎头）；首单回本。

**指标**
- 北极星：从推荐到面试的转化率。KPI：应聘邮件平均自动化回复率、人才库"高潜专家"实时更新率。OKR：年度监测高净值技术人才破 50,000 名。

**坑**
- 简历造假：用历史代码提交频率与技术关键词重合度交叉验证，"代码不会骗人"。
- 客户跳单：前期只提供脱敏技术力报告，签"数据服务合同"明确即使直接入职也需支付对应数据查询费。
