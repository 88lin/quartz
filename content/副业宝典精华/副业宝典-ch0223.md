> 可信度 ★★★☆☆｜类型：广告（工具站）｜变现：漏斗建模费 ¥5,000 + 按线索付费 ¥150-¥500/条｜门槛：低 + Search API 与落地页自动化

百度/Google 大词投放基本亏钱。卖"绕过昂贵大词、用 LLM 长尾语义捕捉即刻想下单的意图、AI 自动写 1,000 个切入点文案"的 SEM 获客系统，按 Pay-per-Lead 收精准线索费。（广告投放簇 ch205/220/223/225/226/227/231/232 同源，本章为搜索意图版。）

**做法**
- MVP（¥500 广告测算预算）：严禁直接采购几十万的 SEM 管理软件。第一步：用 Search API（Serper、Google Search Console）针对 1 个赛道（上海高级月子中心）跑出"高转化意图长尾词库"；第二步：LLM 自动生成每词对应的"极速落地页"模板，API 自动化投放；第三步：按有效线索收费 ¥100-¥300 验证变现。
- 引流：知乎/LinkedIn 发"为什么你的 SEM 成本越来越高？因为你还在用 Excel 做投放"，晒自动化意图分析图；发《2025 全行业搜索意图分布》。
- 钩子：领《2025 意图获客：如何通过 100 行 Python 代码反向截获竞品的搜索流量》。
- 模拟案例（小A）：做"牙科引流机"，发现隐形牙套用户搜的是"哪个牙套戴了不痛""某某品牌和某某品牌的区别"，脚本抓上千个细碎问题、AI 生成上千个答疑页，线索成本只有同行五分之一，把线索流卖给大型诊所月入超 10 万，每天只花 1 小时看告警。

**账本（书中推演数字）**
- 服务 10 家本地高净值服务企业（每家月需 20 个精准咨询线索）；启动成本 ¥0。
- 全案线索漏斗建模费 ¥5,000；每个有效线索技术服务费 ¥150-¥500；单月毛利 ¥2万-¥8万+（除 API 与广告硬费几乎无人力成本，一人可同时服务 20 家）；首单回本。

**指标**
- 北极星：从点击到有效线索的转化倍率。KPI：关键词库自动化拓充速度、CPL 相对行业平均的降幅。OKR：年度生成高质量搜索线索破 10,000 条。

**坑**
- 关键词侵权：投竞品品牌词导致法律诉讼——所有自动生成词库必须过黑名单法律库。
- 预算失控：脚本 Bug 一夜烧 10 万——设硬性日消耗熔断开关与实时余额告警。
