> 可信度 ★★★☆☆｜类型：广告（服务外包）｜变现：管理费 5%-10% + ROAS 超额分成 10%-20% + 素材订阅 + 私有化部署｜门槛：中 + 跨平台 API 集成与规则引擎

传统广告公司靠人力，"架构师型"广告公司靠系统：把投放逻辑代码化（Marketing-as-Code），一个人可支撑一家中型代理公司的业务规模。目标客户：出海 Shopify 卖家、游戏初创团队、需要高频测款的 D2C 品牌。（广告投放簇 ch205/220/223/225/226/227/231/232 同源，本章为代理机构版，无案例。）

**做法**
- 自研投放中台：后端集成 FB/Google/TikTok SDK 的跨平台聚合面板，一个后台管全球流量；规则引擎代码化定义"若 ROI <1.0 且消耗 >$50，则立即停掉该计划"，7x24 无人值守。
- 素材流水线：SAM + Diffusion 自动抠图生成真实场景图（普通杯子置于雪山/海边/现代厨房）；MoviePy 批量剪辑产品亮点视频，自动生成不同尺寸和 BGM 的素材。
- 工程实践：用 Airbyte 或自研脚本把各平台广告数据同步至 BigQuery，构建 LTV/CAC 全链路看板；广告数据与后端 CRM 打通，按用户终身价值动态调整竞价。
- 壁垒：不同行业的最佳策略包（Golden Rules）沉淀为不可复制的代码资产；随投放量增大申请各大平台高级 API 权限，形成天然壁垒。

**账本（书中推演数字）**
- 管理费 + 效果分成：投放金额的 5%-10% 基础技术服务费；超过盈亏平衡点（ROAS）部分提 10%-20% 纯利润奖励。
- 素材订阅制："AI 素材无限包"每月固定费用。
- 系统私有化部署：为有实力的甲方收数万至数十万项目费。

**指标**
- Architect's Insight（原文）：不要定位"代理人"，要定位"代理系统"——建立一个能自我优化的流量循环，让代码在云端完成最枯燥的买卖。

**坑**
- 数据孤岛：各平台口径不一，必须先统一归因再谈优化。
- 过度依赖单一平台 API：多平台冗余接入，防止权限变动导致服务中断。
