> 可信度 ★★☆☆☆｜类型：内容｜变现：按字数付费 + 角色互动订阅 + IP 授权｜门槛：中——LLM API 成本控制与内容风控

AI 交互式小说站：LLM 生成剧情 + 图数据库存世界观保证几百万字不崩 + 每个角色一个独立 Agent（还能跑到微信/Discord 与粉丝互动），读者点选分支按字数付金币，卖阅读消耗、角色私密对话、剧情软广和 IP 授权。无案例、无任何数字。

**做法**
- Graph-based 长期记忆：地理/种族/等级/剧情锚点入图，防长篇世界观崩塌
- 角色即 Agent：个性化 Prompt 定义，小说外社交平台持续运营人设
- AI 按热门小说模板批量生成标题简介，做 SEO/ASO 引流
- MVP：无限流/快穿/诡秘风等强逻辑易参数化品类先行；WebApp 点选分支实时生成

**账本（书中推演数字）**
- Token 计费阅读、角色私密对话/语音连麦付费、免费章节 AI 软广植入、爆款世界观授权游戏厂商
- 原文无任何价格与成本数字

**坑**
- 原文唯一风险项：LLM 输出与用户可见内容之间设 Guardrails 内容过滤器，保监管合规
- 长文生成的 API 成本未核算
