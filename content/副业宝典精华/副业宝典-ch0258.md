用 WebGL/Shader 做"活的桌面"：GPU 加速的粒子系统、流体模拟、音频可视化动态壁纸，宣称 CPU 占用低于 1%，加 GitHub 热力图、币价看板等数据 Widget，客户是极客、电竞玩家。极客玩具向项目，无案例无收入数字。

**做法**
- GLSL 写引力场/赛博朋克雨/分形几何等动效
- Web Audio API 捕捉系统声音，壁纸随音乐节奏跳动
- 壁纸挂 GitHub 提交热力图、加密货币报价、系统资源监控
- Buffer 二进制流按需加载，4K 视频/着色器毫秒级预载
- MVP：Wallpaper Engine 创意工坊作品吃 Patreon/爱发电赞助；网页在线试玩引流
- 进化：Socket.io 手机电脑联动，摸手机屏幕电脑壁纸出涟漪
