---
title: ZKP 链上投融资协议
---

> 可信度 ★★☆☆☆｜类型：Web3｜变现：融资抽成（0.5%–2%）+ 验证接口授权｜门槛：高——ZKP 工程与多辖区合规

用 ZKP + DID 重构一级市场尽调：创业者零知识证明"去年营收过千万"而不暴露客户名单，投资人用 DID 证资金实力与履历，融资款锁在智能合约按里程碑（代码过预设测试集/链上指标达标）自动释放，链上记录 VC 履约形成不可篡改"投资人信用分"。客户是 Web3 初创与硬核科技创业者。全章无案例无数字。

**做法**
- ZK 尽调网关：连银行/支付 API 生成流水真实性证明，投资人只见证明结果
- 代码复杂度 + 更新频次生成代码资产信誉分
- Milestone Lock：融资款按里程碑分阶段自动释放
- MVP：不碰资金的投后透明看板（接 SaaS API 出去隐私看板）；已融资项目的股权 Secondary 智能合约过户

**账本（书中推演数字）**
- 协议抽成：每笔融资通过合约释放时抽 0.5%–2%
- 投资机构"高级验证接口"授权费
- 项目数据包顾问费，帮项目对接顶级 VC

**坑**
- 原文唯一风险项：按 SEC 等各地规则写"合规性监听器"做自动化合规审计
- 证券型代币的多辖区合规远比一个监听器复杂，原文未展开
