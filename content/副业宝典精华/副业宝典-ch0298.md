---
title: 猎头人才预言机中台
---

> 可信度 ★★★☆☆｜类型：服务外包/SaaS｜变现：成功推荐分红 + 人才池月订 + C 级背景审计｜门槛：中 + 全网公开数据工程 + 猎头交付渠道

用 GNN 和 LLM 把猎头从打电话变成算法驱动：爬 GitHub 提交历史、StackOverflow 回答质量、Arxiv 引用与社媒技术讨论，为每个人画"技术雷达图"替代简历关键词匹配；监测活跃度异常波动（突然大量更新文档、star 非当前公司相关项目）标记"潜在活跃"候选人，在离职念头出现前夕精准邀约；LLM 模拟首轮面试追问细节识别简历包装，初筛抹除性别、年龄、院校只看代码可演化性与逻辑严密性；再自动生成提及"你最近修复的那个 Issue"的个人化邀约邮件。猎头佣金是年薪 20%-30%，算法把搜寻周期压短后的利润差即套利空间。客户是独角兽、要 eBPF 专家等稀缺栈的硬核企业、HRVP。

**做法**
- 垂直赛道"Top 1% 核心人才库"+变动周报（如自动驾驶）。
- 向中小猎头工作室授权追踪与筛查接口。
- C-level 岗位做 3 度关系全路径职业信用调查。
- 进化方向：多 Agent 分别扮演外呼员、技术面试官、谈判专家，90% 自动化闭环。

**账本（书中推演数字）**
- 猎头单笔佣金为年薪 20%-30%（书中唯一硬数字）；人才池月订与背景审计无定价；无成单率与成本推演。

**坑**
- 爬取个人职业数据做商业画像涉个人信息保护，"去身份化"只做了一半——触达仍需真实身份联系方式。
- 跳槽概率误判会直接骚扰在职者，声誉与法律风险高。
- 与 LinkedIn/脉脉等平台的数据条款正面冲突。
