> 可信度 ★★☆☆☆｜类型：服务外包/数据服务｜变现：基金 2% 管理费 + 20% Carry + 技术服务费｜门槛：高 + 基金牌照与 LP 资源

内容与 ch0283 基本相同（同为用数据工程替代人工尽调的一级市场玩法，MVP 同为算法生成的"水下项目"周报），差异：ch0301 把对象锁定 AI 初创——审计 GitHub 仓库健壮性与技术负债、HuggingFace 调用量、算力成本曲线，以"架构审计 + 自动化测试套件换干股"，以 GP 身份收 2% 管理费与退出收益 20% Carry；ch0283 面向全行业做股权图谱撮合，收 FA 佣金。

**做法**
- 图数据库实时绘制全球 AI 竞争格局与"垂直赛道真空区"。
- 按 API 调用增速、开发者活跃度、GPU 空闲率做动态估值。
- 自建算力池按项目紧迫度分配 GPU 时长。

**账本（书中推演数字）**
- 管理费 2% + Carry 20%；孵化服务费与数据报告出口无定价。

**坑**
- 云账单、私有仓库数据的"授权获取"途径含糊。
- 无投资业绩记录的团队根本拿不到 GP 位，前提条件书中回避。
