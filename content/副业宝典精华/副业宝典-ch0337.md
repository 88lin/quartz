内容与 ch352 基本相同，差异：ch337 做单项目技术尽调——多代理扫描 GitHub 识别"硬编码伪装的假智能"、对标 Arxiv 与 HuggingFace 榜单算"模型代差"、从 API 调用与 GPU 消耗还原真实 CAC，输出排除吹嘘的技术价值表，另有"套壳 AI 识别器"在线工具；ch352 用另类数据做早期项目发现与情报订阅。ch337 数字仅：单次尽调 0.5-2 万元、融资成功分佣 0.1%-0.5%，无账本推演与案例。

**做法**
- 设想的 MVP：输入 AI 产品名或后端 API 即分析其用了哪些开源模型、评估原创溢价比例；给融资团队一键生成技术尽调报告当融资 PPT 附件。

**账本（书中推演数字）**
- 数字仅单次尽调费 0.5-2 万元与融资分佣 0.1%-0.5%；无成本与收入推演。

**坑**
- 创业者授权接入 GitHub/云平台的权限链敏感；尽调结论对投资决策的责任边界未提；无案例。
