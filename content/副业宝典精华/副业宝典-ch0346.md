> 可信度 ★★★☆☆｜类型：服务外包/工具站｜变现：单次扫描+数据报告 499-1200 元、B 端中介 API 授权｜门槛：中——3DGS 建模（Luma AI/Postshot）与本地中介渠道

异地购房最痛的是"货不对板"：采光、层高、装修损耗隔着屏幕全凭中介一张嘴。方案是用手机拍 3 分钟视频，经 Luma AI 或 Postshot 生成可网页交互的 3DGS 模型，配一份 Python 脚本调取的楼盘历史成交价与法拍记录 PDF，打包成"房产远程尽调服务"；明确不做全功能 VR 交易平台，只做单点扫描加报告。北极星指标是模型线上平均停留时长，季度 OKR 是与 3 家头部区域中介完成 API 联调。

**做法**
- 公域：小红书发"异地买房不踩坑：我把 140 平毛坯房搬进了手机里"展示模型旋转缩放；抖音做"第一视角沉浸式看房"直播，改灯光模拟全天采光；闲鱼/淘宝挂"房产远程尽调服务（3D 扫描+产权合规分析）"。
- 私域：导微信后追加"装修前 3D 基准采集"，为装修纠纷留存原始物理证据。

**账本（书中推演数字）**
- 启动成本 ¥2,500（高性能手机/全景相机 + 云渲染订阅）；客单 ¥499-1,200/次，CAC 约 ¥50，交付 2 小时现场+1 小时渲染出文档，单客毛利 ¥350-900（毛利率 70%-75%），约 10 单回本。
- 天花板：个人 ¥1.5 万/月；切 B 端中介批量授权 ¥10 万+/月。

**坑**
- 扫描须取得房主书面授权，否则侵犯隐私；房源信息发布受住建部门监管，需挂靠合规中介主体；光线太差模型会崩，务必白天光照充足时作业。

（模拟案例）程序员小 A 曾在二线城市买房被坑，第一周在小红书发帮朋友扫的样板房，收到 3 个异地购房者咨询；第二周带设备跑 3 个小区、返工两次，交付 3 份交互式 3D 链接，赚到首笔 ¥1,500。核心困难是老破小光线太暗，靠自备大功率补光灯加手动平衡曝光解决。
