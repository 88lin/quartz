> 可信度 ★★★☆☆｜类型：服务外包/工具站｜变现：会员群 ¥199/月、代换服务费 ¥2,000+/次｜门槛：中——Python 爬虫与航司常旅客知识

中产手里攥着大量信用卡与飞行积分，却不懂跨联盟最优兑换（如用维珍里程换全日空头等舱），积分动态贬值只能躺灰。方案是 Python 脚本每日监控 20 条热门回国/度假航线的里程票位，整理成"今日里程红利表"按会员制发布，再提供 1 对 1 里程资产规划与单次代换；明确不做 ExpertFlyer 式全自动实时订票系统，先卖信息和跑腿。北极星指标是单客积分兑换价值增长率，季度 OKR 是打通 5 个主流航司联盟的底层爬取。

**做法**
- 公域：小红书"500 块玩转公务舱：全网最全里程兑换公式"；飞客茶馆/知乎写国泰、南航票池算法与放票规律的技术贴立权威；视频号拍脚本秒杀热门日期奖励票的实操。
- 私域：1 对 1 帮用户盘点名下所有积分，输出最优利用路径。

**账本（书中推演数字）**
- 启动成本 ¥300（云服务器 + 抢票 API 订阅）；客单 ¥199/月入群费或 ¥2,000+/次代换，CAC 约 ¥80，交付 10 分钟脚本查询+30 分钟下单，单客毛利 ¥1,500+（毛利率 80% 以上），服务型首单即回本。
- 天花板：个人 ¥2.5 万/月；发展二级代理 ¥20 万/月。

**坑**
- 严禁买卖积分本身，只能以"代订/管家服务"名义操作；高频爬取触发反爬，需高质量代理 IP 池与 Headless UI；里程票确认周期长且不可退换，必须与客户签免责声明。

（模拟案例）程序员小 B 原先在各论坛义务答疑，写脚本专盯"中美往返"稀缺票位：第一周在飞客发 3 篇干货引 50 人进微信，第二周帮留学生用 5 万里程抢到价值 ¥2.5 万的商务舱、收 ¥2,000 技术服务费。反爬升级后放弃高频爬取，改订 AwardHacker 类商业 API 做二次逻辑清洗。
