小说推文（知乎盐选、番茄小说分销）是最火的流量转化路径，但很多博主用劣质录屏或无关素材，转化率极低。做 AIGC 产线：输入小说文字 → 自动分镜 → AI 生成图片 → 配音 → 成片，单条成本不到 5 块钱。切片/二创工具簇与 [[副业宝典-ch384]] 同源，差异：本章是"从文字生成"，核心壁垒是主角人设一致性。

**做法**
- 拒绝过度开发：不自己训练模型。核心流程：输入一段文字 → GPT 提取分镜 → SD 生成图片 → 剪映草稿批量导出；杀手锏：主角人设一致性（LoRA 训练服务）；技术栈 Stable Diffusion API + ElevenLabs（或国产语音引擎）+ Python
- 验证（原话）：小红书搜"小说推荐"，找只有文字截图的博主，问："如果能把你的小说片段，根据情节自动生成对应的精美 AI 图片并配上解说语音，一个视频不到 5 块钱，你愿意试试吗？"
- 交付：先做"代制作"服务（手动跑程序交付），验证需求后再做成 SaaS 工具
- 获客：小红书/视频号展示"当顶级小说遇到顶级 AI 画面"的视觉冲击视频；CSDN/掘金发教程"如何用 Python 自动化生成小说短视频"；对推文培训机构提供"工具集成包"作课程配套资源
- 案例（模拟案例）：小 A 业余钻研 SD，帮做小说推广的朋友做了几个高质量视频，点击量翻了 3 倍；生成图片里人物经常"变脸"，引入 IP-Adapter 插件锁定人物长相；消息传开后，10 多个推文主排队买这套"自动化产线"
