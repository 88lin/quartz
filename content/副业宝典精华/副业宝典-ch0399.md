> 可信度 ★★★☆☆｜类型：服务外包｜变现：周报 ¥99/月 + 定制脚本 ¥1,999/个｜门槛：中——海外代理 IP + 反爬对抗

亚马逊已经红海，TikTok Shop（美区/东南亚）正当时。程序员不开店，做卖家的"耳朵"和"眼睛"：监控哪些品类在爆发、哪些达人在带货，告诉卖家机会在哪。爬虫监控簇打法与 [[副业宝典-ch381]] 相同（定时抓取 + 关键词/指标监控 + 自动推送 + 卖服务不卖源码），差异：监控对象从同城评论换成跨境商品与达人数据。

**做法**
- 拒绝过度开发：不做超大型的数据平台。数据抓取机器人：Playwright 定时抓 TikTok Shop 网页端数据（或第三方 API 聚合）；核心功能：黑马监控（24 小时内销量增长率超 300% 的单品）、竞品动态追踪（对手店铺上新和调价）、达人关联分析（爆款背后的核心带货达人清单）；每日自动生成 Excel/PDF 推送微信/Telegram
- 验证：在跨境电商群发截图"这是我用脚本抓出的美区 TikTok 昨天单品销量增长前 50 名，想要完整版的加我私发"
- 获客：知乎/公众号发"我是如何靠一行 Python 代码提前 3 天发现爆品的？"；视频号录屏展示脚本自动抓取分析的过程，突出"科技感"；对跨境电商培训班提供"定制抓取工具"当高端赠品
- 技术栈：Python + Scrapy + Redis（去重）+ 钉钉/企微机器人
- 案例（模拟案例）：小 A 给做跨境的朋友写了选品脚本，朋友按脚本选的"解压灯"在菲律宾站爆了；经常被封 IP 导致数据中断，引入动态代理池策略，并在数据缺失时增加 AI 补全预测逻辑；消息在跨境圈传开，现在每天只需半小时维护服务器，就能拿到几千块数据订阅费

**账本（书中推演数字）**
- 启动成本 ¥1,000（国外 VPS + 代理 IP）；定价：基础周报 ¥99/月、定制监控脚本 ¥1,999/个
- 单客毛利 ¥1,500+（主要靠技术复用）；签下第 1 个脚本定制客户回本
- 收入天花板：维护一个 200 人的付费数据群，月入 2 万+

**指标**
- 北极星：用户在群里反馈的"选品准确率"；KPI：数据更新频率、脚本运行稳定性（防封号率）
- OKR：覆盖 TikTok Shop 全球主流 5 个国家数据；从抓取到报告生成全链路自动化、人工干预 <10 分钟/天；获得 10 名以上月销千万级大卖家的长期订阅

**坑**
- TikTok 反爬极强，需要高质量海外代理 IP 和频繁更换 User-Agent
- 仅抓取公开页面数据，严禁触碰任何用户隐私
