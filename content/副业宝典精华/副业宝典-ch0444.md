> 可信度 ★★★★☆｜类型：服务外包（技术帮装）｜变现：远程安装 ¥199-399/次 + 企业内训 ¥2,000-5,000 + API/VPS 分销 10%-20%｜门槛：低——纯个人技能，零启动成本

Anthropic 发布 Claude Code、开源社区推出 OpenClaw（原 Moltbot）后，AI 编程和智能体进入"命令行时代"，但配置 Node.js 环境、依赖、API Key、终端代理对非技术创业者仍是天堑。程序员卖"安装+基础培训"一站式服务，赚高毛利辛苦费，并向长期技术顾问转化。

**做法**
- 需求验证：闲鱼、小红书发布"Claude Code 远程协助安装""OpenClaw 智能体部署"等关键词，观察询单量；或在技术社群回答安装问题留存潜在客户。
- "五合一"全家桶：①环境配置——终端代理（Clash/V2Ray）、Node.js、Git 环境搭建；②工具部署——手把手安装 Claude Code 和 OpenClaw，确保正确连接并调用 API；③API 托管/代购——给没有海外信用卡的用户代购 API 额度赚手续费；④工作流演示——用 Claude Code 重写代码、用 OpenClaw 监控网页或回复消息；⑤售后——一个月远程调试期（版本更新失败等）。
- 交付方式：向日葵/ToDesk 远程桌面安装，或一线城市提供高客单价的"上门部署"。
- 模拟案例（模拟案例）：老周发现外贸公司老板想用 Claude Code 写脚本自动处理订单但折腾一天没装上，闲鱼挂链接首单 99 元引流，第一天接 5 单；装工具之外送自写"外贸自动催款邮件脚本"模板，转型为这些老板的长期技术顾问，每月代运维+定制脚本多赚一万多。

**账本（书中推演数字）**
- 启动成本 ¥0（只需个人技能和稳定的代理环境）。
- 定价：远程安装包 ¥199-399/次；企业内训包 ¥2,000-5,000（含办公自动化工作流搭建）；API Key 充值、VPS 租赁分销额外获利 10%-20%。
- 回本周期：即时回本。

**指标**
- 北极星指标：老客户转介绍率。
- KPI：单次客单价（AOV）、安装成功率及客户满意度评分。
- OKR：沉淀《Claude Code/OpenClaw 安装与避坑白皮书》；积累 50 个五星好评的真实成交案例。

**坑**
- 安全：远程操作前提醒客户 API Key 的安全性，不在公共电脑部署，配置文件加密。
- 交付效率：部分客户的 Windows 环境权限问题极复杂，提前备好一键脚本或 Docker 镜像压缩交付时长。
- 额度纠纷：安装完成后的测试环节务必提醒客户调用的是付费 API，避免演示消耗过多额度产生纠纷。
