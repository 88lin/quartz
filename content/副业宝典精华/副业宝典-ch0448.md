> 可信度 ★★★☆☆｜类型：工具站/开源产品｜变现：内置 API 额度转售 + Pro 订阅 19/月 + 企业私有化 5000-20000｜门槛：中——需强工程能力

对标 Aider/OpenCode/Cursor：做"国内模型友好 + 本地离线 + 可私有化"的 AI 编程 CLI，工具免费、靠内置充值和订阅赚钱。痛点：Cursor 每月 140+ 元且不支持微信/支付宝；政企金融禁止代码出海外模型；现有 CLI 中文优化差。

**做法**
- 验证：看 Aider/Mentat 的 Star 趋势；掘金/V2EX 搜"本地代码 AI 助手""DeepSeek 编程"；听社群对 Cursor 替代品的呼声。
- 核心工程：Tree-sitter 提取文件依赖与核心类/函数定义，生成"Repo Map"，只带相关上下文——单次 Token 压缩 70% 以上（这是成本与体验的命门）。
- 双通道：本地 Ollama 跑 Qwen2.5-Coder/DeepSeek-Coder（零泄露、零代付成本）+ 云端中转通道（流式输出 Diff）。
- 自动修 Bug 闭环：授权执行 `npm test`/`pytest`，失败自动带报错回喂模型迭代到通过。
- 技术栈：Node.js (Commander/Inquirer) 或 Python (Typer/Rich) + Tree-sitter + Git API + Ollama SDK。
- 模拟案例（模拟案例）：架构师老张写 Spring Boot+React 专用 CLI"CodeCatcher"发 NPM，博客文《本地 Qwen 自动写 100% 覆盖率单测》引流；云端增强 9.9 元/1000 次重构额度 + 本地企业版包年 1999；半年周下载 2000+，月被动 8000 元 + 两单私有化 3 万+。

**账本（书中推演数字）**
- 启动 ≈0（电脑 + 50-100 元 API 测试费；GitHub/NPM/PyPI 免费）。
- 收益：内置渠道 1 元 = 50 万 Token（对 DeepSeek 官方价 2-3 倍溢价，卖的是加速和开箱即用）；Pro 版 19/月或 129/年（多文件重构/自动单测/架构审计）；企业私有化 5000-20000/项目。
- 回本：首批 10 个订阅或 100 个充值用户即纯盈利。

**指标**
- 北极星：每周活跃执行修改次数。KPI：免费转 Pro >3%、代码采纳率 >70%、充值复购率。OKR：单次修改 Token <8000、采纳率 >75%、NPM 下载破万。

**坑**
- Agent 能执行本地命令：严禁 `rm -rf`、端口监听、上传敏感文件，任何 shell 命令前必须终端显式确认（Y/N）。
- 强制干净 Git 工作区运行，修改前自动建临时分支或 stash，可一键回滚。
- 大项目长上下文衰减：做好分块（Chunking）与召回，只喂关联度最高的片段。
