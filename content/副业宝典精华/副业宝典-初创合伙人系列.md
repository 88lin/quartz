> 仓库 README 外链系列《写给 0-1 岁的初创公司合伙人》31 篇（CSDN/掘金）。定位是 VC 视角的创业公司管理科普（股权、融资、董事会、合规），与"程序员副业"主题错位——对独立开发者/一人公司直接有用的约 8 篇，其余在做大之后才用得上。

## 与副业直接相关的 8 篇（值得读）

| 篇 | 要点 |
|---|---|
| LTV/CAC 单位经济模型 | 健康线 LTV/CAC ≥3；CAC 要算完全负载（含人力工具）；CAC 回本期 ≤6 个月优秀；LTV 只算 12-24 个月防高估 |
| 留存率 | 40-20-10 法则（次日 40%/7 日 20%/30 日 10% 为及格线）；留存比拉新杠杆高 5-7 倍；SaaS 看 NRR >100%；先找到 Aha 时刻 |
| 全球支付通道 | Stripe 账面 2.9%+$0.3，叠加汇损/拒付/提现实际 5-8%；PayPal 偏袒买家、综合 4.4-6.4%；欧美双通道覆盖 80%，东南亚补本地钱包 |
| 烧钱率 | 月净烧钱率 = 上月现金 − 本月现金（剔除未到账）；存活月数 = 现金 ÷ 净烧钱率再打 5 折 |
| PLG vs SLG | 客单 <1 万元/年适合产品驱动，>10 万必须销售驱动，1-10 万是死亡区；可"PLG 获客 + SLG 成交" |
| 上线自查清单 | 落地性、安全、可靠性、性能、成本五维 + 事件响应机制 |
| 出海推广渠道与技术栈 | 七大平台社交阵地优先；围绕效率、成本、风险三痛点选型 |
| 逆向思考法 | Pre-mortem 四步：假设倒闭 → 归因 → 算概率 → 倒推行动；初创三大死因：现金断流、团队内讧、伪需求 |

## 做大之后才需要的 23 篇（一句话备忘）

- **融资类**：融资轮次科普；SAFE 比可转债结构更简单；可转债与可转换优先股的债权/股权属性；LTV 之外的 MAU/ARR 口径辨析（警惕短期优惠制造的"无质量增长"）。
- **股权类**：动态股权分配（反对 50/50 拍脑袋）；ESOP"三个篮子"设计与两个极端陷阱；VIE 架构的红线与红利；ODI 备案是资金出境正路，"蚂蚁搬家"换汇涉逃汇。
- **条款类**：反稀释——完全棘轮对创始人最狠，加权平均更公平，2023 年市场估值普降 30-50%；董事会管理——早期 ≤3 人、保半数席位、会前一对一"前馈"；VC 尽调本质是证伪，约 100 个问题查团队。
- **增长与组织**：网络效应（指数增长+护城河）与规模效应（仅成本优势）的"翻倍测试"判别；过度定制化两头落空；A 级人才雇 A 级人才，识别雇佣兵与传教士；远程跨时区管理防信息不同步（60% 知识工作者每周远程 ≥2 天）；品牌是"在算法里被认得"，不是打广告。
- **合规与退出**：GDPR/CCPA 是能定生死的非经营性风险；商标抢注与前员工带走代码是 IP 两大典型事故；并购与退出时机（2023 全球 IPO 处历史冰点）；复盘与决策日志对抗 20 多种认知偏差。
- **定价与心法**：成本加成三陷阱；价值定价 = 提取价值增量的 10-20%，约 20% 客户嫌贵说明定价到位；"长期贪婪"——声誉是唯一无法用钱快速复制的资产。
