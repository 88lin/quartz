# 一、三层生意

| 层 | 交付 | 客单价 | 启动成本 |
|---|---|---|---|
| 代装 | 小时级，远程桌面 | 199-399 元/次，引流单 99 | 0（梯子+技能） |
| 私有化部署 | 天级，上门或远程 | 2000-1 万元/次 | 0-2000（自建演示环境） |
| API 中转站 | 持续收租 | 官方价 1.1-1.5 倍 + 席位费 | 200-500 元/月服务器 |

# 二、代装：五件套服务

目标人群：想用 Claude Code/OpenClaw 但被 `npm` 报错、Docker 配置失败、终端代理不通挡在门外的非技术用户——独立开发者、跨境电商卖家、初创企业主。

1. **环境配置**：终端代理（Clash/V2Ray）、Node.js、Git。
2. **工具部署**：装好 Claude Code 和 OpenClaw，确保能连上 API。
3. **API 托管/代购**：帮没有海外信用卡的用户代充额度，抽 10-20%。
4. **工作流演示**：演示用 Claude Code 重写代码、用 OpenClaw 监控网页/回复消息。
5. **售后**：一个月远程调试期（版本更新失败等）——这是复购入口。

交付方式：向日葵/ToDesk 远程，一线城市可做高客单"上门部署"。企业内训包 2000-5000 元/场（含办公自动化工作流搭建）。

**验证**：闲鱼、小红书发"Claude Code 远程协助安装""OpenClaw 智能体部署"，看询单量；或在技术社群持续回答安装问题沉淀客户。

**书中模拟案例（虚构人物，看链路）**：运维老周闲鱼挂 99 元引流单，首日成交 5 单；交付时送一套自写"外贸自动催款邮件脚本"模板，从此变成这批老板的长期技术顾问，代运维+定制脚本每月多赚一万多。

**坑**：客户 Windows 权限问题极复杂，提前准备一键脚本或 Docker 镜像压缩交付时长；演示环节调用的是付费 API，必须提前说明，避免额度纠纷；远程操作前提醒客户 API Key 安全（配置文件加密、别在公共电脑部署）。

# 三、私有化部署 + 知识库

**谁在买单**：数据不能出内网的行业（政府、医疗、金融）；每月 Token 费过万、自建算力更便宜的重度用户；想要本地知识库的律所、科研团队。

**方案三层**：
1. **一键部署脚本**：Docker + Ollama/vLLM，适配从 A100/H800 到消费级 4090——脚本化程度越高毛利越高，书中 OKR 是"10 分钟内完成全模型栈安装"。
2. **RAG 知识库**：不只是装模型，把 Dify/Clawdbot 前端接上客户的 PDF/Word/飞书文档，做成"企业大脑"。这一步才是客单从 2000 跳到 1 万的原因。
3. **量化适配**：客户只有 16G 显存时给 AWQ/GGUF 量化方案，平衡速度与精度。

技术栈：Ollama + vLLM + Docker + Python（系统运维）+ Dify。

**收入结构**：单次部署 2000-1 万/次；代运维 retainer 500-2000 元/月/客户。回本周期 = 谈下第一个企业订单。

**模拟案例（虚构）**：帮律师朋友的 4090 工作站跑通 DeepSeek，发现律师真正要的是"秒搜数千份卷宗"，于是加 RAG + 极简侧边栏对话界面，数据不出办公室——最后成了三家律所的"AI 技术合伙人"，年维护费超过工资。

**坑**：显卡驱动和 CUDA 版本是最大坑，必须维护硬件兼容清单；模型更新极快，合同写明免费更新次数、超出收费；私有化 ≠ 合规豁免，仍要告知客户遵守生成式 AI 管理条例。

# 四、API 中转站——能做但有灰色属性

**痛点**：国内开发者付不了海外订阅费；企业多团队共用一个 Key 算不清成本；单一供应商封号业务就停摆。

**方案**：用开源 One-API/New APIs 搭统一网关（用户只改 `BASE_URL` 和 `API_KEY`）→ 多渠道负载均衡 + 自动重试（99.9% 可用性）→ B 端控制台（发 Key、设额度、按日/按模型调用日志、计费账单）。技术栈：One-API（Go/React）+ Docker + Redis + PostgreSQL + Nginx。

**定价**：Token 差价 1.1-1.5 倍 + 企业"管理费/席位费"；启动成本 200-500 元/月（香港/海外服务器）；回本点 ≈ 20 个活跃企业调用者。

**三个真实风险（书中自己列的）**：上游风控封号（量大必触发，多账号多地域散列只能缓解）；DDoS 与盗刷（QPS 限制、IP 黑白名单、欠费自动断连）；资金链（上游预充值，下游增长越快垫资压力越大）。这一层做成合规生意的关键在渠道和账单合法，个人轻量做可以，当主业扩张前先想清楚。

**模拟案例（虚构）**："一块钱两万 Token"的简单定价，路由优化后比直连还快、支持国内支付，日中转 Token 以亿计——数字属推演叙事，可参考的是"比直连快 + 支持国内支付"这两个真实卖点。
