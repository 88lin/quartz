## 项目逻辑

三层生意，客单从低到高：

1. **代装**（小时级交付）：装 Claude Code / OpenClaw 这类 CLI 工具。痛点是 npm 报错、Docker 配置失败、终端代理不通。闲鱼/小红书挂"远程协助安装"，ToDesk/向日葵远程交付。
2. **私有化部署 + 知识库**（天级交付）：把 DeepSeek 等模型用 Ollama/vLLM 部署到客户自有机器，接上 Dify 等前端 + 客户的内部文档做 RAG。客户动机：数据不能出内网（律所、医疗、政府供应商）、重度使用者的 Token 费已超过自建成本、要绕开公有服务的审查与限流。
3. **API 中转站**（持续收租）：用 One-API 聚合各模型，统一 OpenAI 格式接口，按 1.1-1.5 倍官方价转卖 + 企业席位费。注意这一层偏灰：上游封号风险、预充值垫资、支付合规，书中明确列为风险而非卖点。

## 账本（书中的报价为价格锚点，收入为推演）

| 项目 | 价格锚点 | 成本侧 |
|---|---|---|
| 远程安装 | 199-399 元/次（引流单可 99） | ≈0，只有时间 |
| 企业内训 | 2000-5000 元/场（含办公自动化工作流） | 备课时间 |
| 单次部署 | 2000-1 万元/次（看模型规模 + 知识库复杂度） | 启动 0-2000（自建演示环境） |
| 代运维 retainer | 500-2000 元/月/客户 | 模型更新、故障处理 |
| API 代充/代购 | 抽 10-20% | 垫资 |

推演模型：10 个部署客户 + 10 个运维客户 ≈ 月 1.5-3 万。书中模拟案例（虚构人物）：运维工程师闲鱼挂 99 元引流单，首日成交 5 单；帮律所在 4090 工作站上跑通"卷宗秒搜"，后续做成三家律所的"AI 技术合伙人"，年维护费超过工资——案例只能说明链路成立，金额不可当预期。

## SOP

1. **验证**：闲鱼/小红书发"远程安装 Claude Code"看询单量；或 LinkedIn/商务群里观察"DeepSeek 离线部署"的咨询密度。
2. **产品化**：做一键部署脚本（Docker/Ollama/vLLM 多显卡适配）+ 硬件兼容清单。交付时长越短毛利越高，脚本化是把 199 的单做成 400 时薪的关键。
3. **五件套交付**：环境（Node/代理/Git）→ 工具部署 → API 代购 → 工作流演示 → 一个月远程售后。售后是复购入口，升级为企业内训和 retainer。
4. **B 端升级**：单机部署 → 加 RAG 知识库（客户 PDF/Word/飞书文档）→ 按量化方案（AWQ/GGUF）适配客户硬件 → 转长期运维合同。

## 风险与坑

- **显卡驱动和 CUDA 版本是最大坑**，必须维护硬件兼容清单，否则一次交付翻车烧掉口碑。
- **模型更新极快**：合同里写清免费更新次数，超出另收费，否则运维是个无底洞。
- **API 中转的上游风控**：量大必封号，多账号多地域部署也只是缓解；垫资压力大，下游增长越快现金流越紧。此层仅建议有闲钱垫资时做。
- **演示消耗客户付费额度**要提前说明；远程操作注意客户 API Key 安全，别在公共环境部署。
- 私有化 ≠ 合规豁免，生成内容仍受生成式 AI 管理条例约束，交付时要告知客户。
